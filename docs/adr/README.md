# Architecture Decision Records

Toda decisão cara de reverter mora aqui. Formato: **Contexto → Decisão → Consequências →
Alternativas descartadas**.

Um ADR não se edita depois de aceito. Se a decisão mudar, cria-se um novo ADR que
substitui o anterior, e o antigo passa a `Substituído por ADR-XXXX`. O histórico do
raciocínio é o que dá valor ao registro.
